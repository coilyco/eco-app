# Path D worked - inline Amplitude chart without MCP Apps

2026-04-20 ~15:42 PT. Original: `git show b012073:investigation/1776725700_06_path_d_worked.md`.

## What happened

Writing `~/projects/amplitude-error-rate-chart.html` fired CCD's `PostToolUse:Write`
hook, which opened the file in the Launch preview panel with no `Edit`. Correction to
the sibling README: **both `Write` and `Edit`** trigger it.

The page: a 60-day line chart (raw daily error rate as blue dots, orange above 0.5%,
a pink dashed trendline) and a stats grid (average, peak, spike count, trend start and
end). All data came from the earlier `render_chart` call. No iframe, no new server.

## Why it answers Kai's ask

Kai wanted an Amplitude chart inline via the MCP Apps spec. That path is a client-side
limitation in CCD, but the goal of inspecting the chart inline is met.

## Pattern for inline visuals in CCD

1. Call the MCP tool that returns the data.
2. Write a self-contained HTML file with the data inlined as `<script>` JSON.
3. The Launch preview opens through `PostToolUse:Write`.

## Limitations

- CCD only. Not Claude Desktop chat, not the Claude Code CLI.
- The file must sit in a path CCD trusts. The project root works, `/tmp` is unchecked.
- Spec-compliant MCP Apps rendering still needs Claude Desktop chat or an Anthropic
  change to CCD.
