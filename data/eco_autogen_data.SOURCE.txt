Provenance — eco_autogen_data.json.gz
=====================================

eco_autogen_data.json.gz is generated, not authored. It is a structured summary of
the recipe, skill, and tag definitions that Eco's dedicated server ships as
generated C# under Mods/__core__/AutoGen.

It is stored gzipped (125 KB rather than 1.6 MB) because it is machine-generated
data that no one reads by hand, and leaving 73k lines of it expanded buries every
grep and every diff in this repository. Read it with:

  python -c "import gzip,json;print(json.load(gzip.open('data/eco_autogen_data.json.gz')))"
  gzcat data/eco_autogen_data.json.gz | jq .counts

  Source        : Eco Dedicated Server, Steam app 739590
  Build id      : 25802357 (Eco 0.14.2.0 release-1099)
  Obtained by   : steamcmd +login anonymous +app_update 739590
                  The dedicated server is published as an anonymous-login depot;
                  no Steam account and no game licence are involved. Confirmed by
                  Strange Loop Games on the official Eco Steam discussions.
  Generated by  : scripts/autogen_refresh.py  (just autogen-refresh)
  Parser        : src/eco_mcp_app/autogen.py

Copyright
---------

The underlying game content is:

  Copyright (c) Strange Loop Games. All rights reserved.

as stated in the header of every AutoGen source file. This is proprietary game
data, NOT open-source content, and it carries no licence grant of the kind
eco_gnome_data.json has. It is included here as derived factual game data —
recipe names, ingredient quantities, crafting stations, skill requirements — for
interoperability with a running Eco server. No SLG source code is vendored: the
C# is read and discarded at generation time, and only the extracted values are
kept.

Refresh
-------

Rerun after any Eco version bump:

  just autogen-refresh                    # downloads the server (~514 MB)
  just autogen-refresh --root PATH     # reuses a server tree on disk

The build id above is recorded in the file's own `source` field, so a stale
vendored graph is visible in any payload that serves it rather than silent.
